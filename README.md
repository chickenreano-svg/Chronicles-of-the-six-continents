# Chronicles of the Six Continents — PWA Bundle

## Included Files
- `index.html` — Complete offline-ready RPG with interactive SVG World Atlas, 30-Floor Dungeon of Death, 5 Story Acts, Blind Dungeon Auction, 10 Side Dungeons, 48-Weapon Armory, and Weaponsmith Forge.
- `manifest.json` — Web App Manifest (`standalone` display mode, app metadata, and icons).
- `service-worker.js` — Offline caching service worker (`six-continents-pwa-v1`).
- `icon-192.png` & `icon-512.png` — Maskable PNG app icons.
- `icon.svg` — Scalable vector emblem icon.

## Quick Hosting & Installation
1. Upload all files in this folder to any static HTTPS host (**GitHub Pages**, **Netlify**, or **Vercel**).
2. Open your live HTTPS URL in Chrome (Android/Desktop) or Safari (iOS).
3. Tap **Install App** in the game header (or **Add to Home Screen** in your browser menu) to launch full-screen and play offline.
